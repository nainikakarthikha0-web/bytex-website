A faceless, responsive personal learning website with a futuristic black + neon-green look.

## Pages
- `index.html` — Home
- `experience.html` — My Experience and the Cybersecurity Career Webinar 101 certificate
- `podcast.html` — Podcast landing page and episode notes placeholder
- `learning.html` — Blogs and learning resources
- `projects.html` — Project showcase

- `assets/certificates/cybersecurity-career-webinar-101.pdf` — uploaded certificate

## Language
All visible website copy is in English. English wording has been removed.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `byte-and-beyond`.
2. Upload every file and folder in this ZIP (keep the folder structure).
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear.

## Updating content
For now, edit the relevant HTML file and upload the changed file to GitHub. The podcast page is ready as a design placeholder; add an audio player with your hosted MP3 URL when your first episode is ready. A fully online admin dashboard requires a database/authentication setup and should be configured before public use.
